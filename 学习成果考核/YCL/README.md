## 为什么 L3 有 4 道题

我看过你之前写的两个文件，发现一个共同点：

**你会写 `return`，但经常不接住它。**

`超级难的def.py` 里：

```python
def hello(name):
    print(f"你好,{name}")
    return "haoqi"

hello(name)      # ← 调用完就把返回值扔了，"haoqi" 没人要
```

`进制转换器.py` 里更明显：

```python
进制转换 = 0
for dubug in 输入:
    输出 += intdubug * 进制转换    # 进制转换 永远是 0，乘出来永远是 0
```

那个循环的乘积永远是 0，因为该给 `进制转换` 赋值的地方，没有接住返回值。

**所以 L3 四道题全部围绕 `return`**，第四题最狠。

## 评分标准

我审的时候按这四项看：

| 项 | 权重 | 说明 |
|---|---|---|
| 能跑 | 必须 | 不报错，输出和示例一致 |
| 逻辑对 | 高 | 边界情况（等于、0、空列表）处理对不对 |
| 命名清楚 | 中 | 变量名看得懂就行，中文变量名完全可以 |
| 代码干净 | 低 | 不要求一行解决，但别复制粘贴 |

**一条要紧的：代码有 bug 但你自己能说清哪儿错，比抄一个正确答案得分高。**

## 卡住了怎么办

先别问我。按这个顺序试：

1. **打印中间变量** —— 在可疑的地方 `print(变量)`，看它是不是你以为的值
2. **跑最小例子** —— 把数据换成 `[1, 2]` 或 `3`，手工推一遍
3. **读报错** —— Python 的报错会指到具体行号，`TypeError` 多半是类型错了

三步都试完还卡着，再来找我，把你试过的东西说一遍。

# D 套：细节训练

前面几套是「写代码」，这套是「预测输出」。

每题给一段能跑的代码。你先猜结果，再运行对比。

| 文件 | 题数 | 练什么 |
|---|---|---|
| D-01 range与循环 | 6 | range 的边界、步长、计数 |
| D-02 if与条件 | 6 | if / elif / 独立 if 的差别 |
| D-03 数字与运算 | 7 | `//` `%` 的负数、`int()` 截断、浮点 |
| D-04 函数与返回值 | 6 | print vs return、引用 vs 复制 |

## 为什么练这个

你的问题不是「不会」，是**凭印象写代码，不凭验证**。

- `九九乘法表.py` 里 `range(1, i+1)` —— 对
- L2-01 里 `range(0, b+1)` —— 错

同一套规则，两次用出两种结果。中间缺的就是「停下来验一次」这个动作。

这套题把这个动作练成条件反射：**写完 → 猜结果 → 跑 → 对一下 → 再往下**。

## 规矩

**先写预测，再运行。**

先跑再看的，这套对你就是零价值 —— 因为你看完结果会觉得「哦原来是这个」，然后下次照错。

## 时间

25 道小题，每题 1–2 分钟，总共 25 分钟能做完。

## 和前四套的区别

L1-L4 是「给你一个说法，你翻译成代码」，写出来就过了。

H 套是「给你一个现象，你自己找原因」。**代码写出来只值 40 分，剩下 60 分在你能不能说清为什么。**

## 卡住的标准

前面几套我说「卡住就喊我」，太模糊。这次给具体数字：

| 题目 | 允许独立思考 | 超时怎么办 |
|---|---|---|
| H-01 | 15 分钟 | 看题面里的提示，再想 15 分钟 |
| H-02 | 不限（第一版本来就要等） | 跑不动就掐掉，直接看第二步 |
| H-03 | 20 分钟 | 降级成 60 分版本，两版 + 耗时一起交 |
| H-04 | 20 分钟 | 看提示二 |
| H-05 | 25 分钟 | 先写死「木材 = 10」的版本，再想着推广 |

**超时不是失败，是信息。** 你卡在哪儿，就说明那个概念没打通 —— 这比做出一道简单的题有用得多。
