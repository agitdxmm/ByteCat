# 教学规范

> 这套教材的所有文件都按这份规范写。改教材前先读一遍。

---

## 一、五条硬规则

这五条是定死的，不商量。

### 1. 每课 4 个文件

一个 Level 有 5 课，一课 4 个文件。L1~L5 一共 100 个文件。

4 个文件不是随便凑的，每个文件负责**一个用法**，四个拼起来把一课的语法讲全。

### 2. 一个文件 = 一个用法讲全 + 3 道综合题

这是最容易做错的一条，说细一点：

- **讲要讲全**：一个文件如果讲 `break`，就把 `break` 的各种情况都讲到 —— 基本用法、和正常结束的区别、`while True + break`、只能跳一层、位置的影响。不能拆成两个文件讲。
- **题要综合**：3 道题不能是「换个数字再做一遍」，要综合运用这个文件里的**所有**用法。做题时得回头翻讲解才能写出来，说明题出对了。

反面例子：讲 `print` 时拆成「打印文字」和「打印多个参数」两个文件 —— 错了，这是一个用法，该放一起。

### 3. 每周 2 课

一周两课，一课 4 个文件。节奏别乱。

### 4. 每个 Level 结束，出 5 道星级综合题

放在 `学习成果考核/初一/上学期/<Level>/` 里。

难度从 1★ 到 5★ 递进。1★ 基本照做，5★ 要综合整个 Level 的东西。

### 5. 考核题不放提示

考核就是考核。题目下面直接留给学生写，不给「提示：可以用 xxx」。

教材里的题可以有引导，考核里的题不给。

## 二、一个文件长什么样

所有教材文件都是这个结构，照着填：

```python
r'''
════════════════════════════════════════════════════════
  L4 · 第 1 课 · 用法 2        增删元素
════════════════════════════════════════════════════════

这一节讲什么，一句话说清楚。

────────────────────────────────────────────────────────
【第一个知识点】
────────────────────────────────────────────────────────

    代码示例用 4 个空格缩进

    输出用这种格式写
    → 结果

────────────────────────────────────────────────────────
【第二个知识点】
────────────────────────────────────────────────────────

    ...

────────────────────────────────────────────────────────
【易错点 / 对比表 / 记忆口诀】
────────────────────────────────────────────────────────

    ...
'''

# ═══════════════════════════════════════
#  示例
# ═══════════════════════════════════════

print("① 第一个示例")
# 代码

print("\n② 第二个示例")
# 代码


# ═════════════════════════════════════════
#  练习：3 道综合题
# ═════════════════════════════════════════

# ─────────────────────────────────────────
#  题 1  ──  标题
# ─────────────────────────────────────────
#
# 要求：
#   · ...
#   · ...
#
# 你的代码：


# ─────────────────────────────────────────
#  题 2  ──  标题
# ─────────────────────────────────────────
#
# ...


# ─────────────────────────────────────────
#  题 3  ──  标题
# ─────────────────────────────────────────
#
# ...


# ═════════════════════════════════════════
#  答案  ——  先自己写完再看
# ═════════════════════════════════════════
r'''
题 1
    # 代码放这里，用 4 空格缩进

    —— 讲为什么这么写

    —— 讲容易错在哪

题 2
    ...

题 3
    ...
'''
```

**四个区块不可少**：讲解区（`r'''` 开头）、示例区、练习区、答案区。顺序不能变。

## 三、写作要求

### 讲解区

- 用 `r'''` 包起来（**不是** `"""`，原因见下面第 4 条）
- 每个知识点单独一个小标题，用 `────` 分隔线隔开
- 代码示例缩进 4 空格，输出用 `→` 或直接贴结果
- 讲「为什么」比讲「是什么」重要。同一个现象要给原因
- 有坑就直说「这是坑」，别绕过去

### 示例区

- 每个示例前 `print("\n② 标题")`，编号用 ①②③
- **必须能跑通**，跑出来什么就写什么
- 示例要递进：先简单后复杂，最后一个示例通常接近实战

### 练习区

- 3 道题，题目用 `#` 注释写
- 每题下面留 `# 你的代码：`
- 题里可以给「提示」，但只给方向不给答案
- **题目下方不放答案**

### 答案区

- 整块放在文件最末尾，`r'''` 包起来
- 每题至少包含：完整代码、为什么这么写、容易错在哪
- 有数字结果的地方，**必须实际跑过再写**

## 四、四个坑（我踩过，别再踩）

### 1. `r'''` 外层，`"""` 内层

文件外层用 `r'''...'''`，讲三引号的时候内层才用 `"""`。

**反了会报错**：外层是 `r"""` 时，内容里出现 `"""` 会提前结束字符串，后面的中文被当成代码，报 `SyntaxError: invalid character '。'`。

### 2. 必须加 `r` 前缀

讲解里会写到路径（`C:\Users`）和转义字符（`\n`、`\u4e00`）。

不加 `r`，`\U` 会被当成 Unicode 转义开头，报 `truncated \uXXXX escape`。

**所以外层永远是 `r'''`，不是 `'''`。**

### 3. 数字必须跑出来

写答案时最危险的是「我觉得应该是……」。

已经栽过的地方：

| 文件 | 我写的 | 实际的 |
|---|---|---|
| L2 第5课 02 | 和 = 2133 | 2632 |
| L4 第2课 01 | 平均 = 78.5 | 79.5 |
| L5 第2课 02 | 账单 60.84 | 60.99 |
| L5 第1课 01 | strip 结果 "hix" | "hi" |

**规则：答案区里出现的每一个数字，都要能对着屏幕上的输出念出来。**

### 4. 代码里的注释符号不能省

```python
raise          ← 记完日志再抛出去     # ❌ SyntaxError
raise          # 记完日志再抛出去     # ✅
```

中文箭头、破折号当注释时，前面必须有 `#`。

---

## 五、另一个必须避免的

**不要在答案区写「思考过程」。**

反面例子（真实出现过）：

```
—— 输出：133

—— 验证：
       133 % 7 = 0 ✓
       1 + 3 + 3 = 7  ✗

   等等，这里不对。重新找。

   实际上是 175：
       ...
```

这段是我的推演记录，不是答案。学生看到只会困惑。

**答案区只放结论。** 算错了就重算，算对了再写进去，中间过程不进文件。

## 六、命名规范

### 目录

```
小喵咪学编程/
└── 初一/上学期/
    ├── L1/第1课/  第2课/  第3课/  第4课/  第5课/
    ├── L2/...
    └── L5/...
```

### 文件

```
01_变量与赋值.py
02_命名规则.py
03_类型与type.py
04_多变量与交换.py
```

- `01`~`04` 前缀，保证按顺序排
- 名字用中文，说明这个文件讲什么
- 不用空格，不用括号

### 考核

```
学习成果考核/初一/上学期/L1/L1考核.py
```

## 七、交付前检查清单

写完一个文件，逐条对：

- [ ] 能 `python 文件名.py` 直接跑通，不报错
- [ ] 示例区的输出和讲解区写的一致
- [ ] 有 3 道题，题目下方没有答案
- [ ] 答案在文件最末尾
- [ ] 答案里的数字都跑过
- [ ] 没有「等等」「我想」「修正一下」这类思考痕迹
- [ ] 外层是 `r'''`，内层示例用 `"""`
- [ ] 文件里没有用到后面 Level 才讲的东西
  （比如 L2 不能用列表，L3 不能用字典）
- [ ] 讲全了，不是只讲了一半

写完一个 Level，再对一遍：

- [ ] 5 课 × 4 文件 = 20 个文件齐了
- [ ] 所有文件都跑过一遍
- [ ] 考核 5 道题写好了，难度从 1★ 到 5★
- [ ] `git commit`

## 八、难度控制的底线

这套是初一教材，**不许超纲**。

| Level | 能用的 | 不能用的 |
|---|---|---|
| L1 | 变量、print、input、运算、字符串、if、while、for | 列表、字典、函数、文件 |
| L2 | 以上 + break/continue、嵌套 | 列表、字典、函数 |
| L3 | 以上 + 函数、递归 | 列表、字典（除了解释多返回值） |
| L4 | 以上 + 列表、字典、元组、集合 | 类、文件、异常处理 |
| L5 | 以上 + 文件、JSON、异常、模块 | 类、装饰器、生成器深入 |

写的时候如果发现「这里得用列表才讲得清」，说明这个知识点还没到时候，先跳过。

**宁可少讲一点，也不能讲乱。**
