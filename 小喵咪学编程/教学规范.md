# 小喵咪学编程 · 教学规范

> 2026-11-07 小喵咪定。D老师执行。

## 一、每课 4 文件

一课 = 4 个 `.py` 文件。

**每个文件 = 1 个用法**（一个独立的知识点），文件内自带讲解 + 示例 + 练习。

命名：`01_用法名.py`、`02_用法名.py`、`03_用法名.py`、`04_用法名.py`

文件内部结构必须一致：

```
顶部文档字符串：这个用法是什么、规则是什么
示例 1 / 2 / 3：能直接跑的示范
练习区：3 道题，只有题目，代码留空
答案区：文件末尾，大段注释包住，看之前先自己做
```

## 二、一个用法 3 道题

每个文件 3 道题，难度按 `1 → 2 → 3` 递进：

- 第 1 题：照抄示例改一点，能跑就行
- 第 2 题：换个场景用同一个用法
- 第 3 题：和别的用法或边界情况撞一下

一课总计 **4 用法 × 3 题 = 12 题**。

## 三、每周 2 课

一周上 2 课。不赶进度，做完一课验收一课。

## 四、Level 结束出综合题

每学完一个 Level（L1、L2……），去

```
学习成果考核/初一/上学期/<Level>/
```

出 **5 道综合题**，难度 **1 星 → 5 星**：

| 星 | 要求 |
|---|---|
| ★ | 单一用法直接套 |
| ★★ | 两个用法拼一起 |
| ★★★ | 需要自己设计流程 |
| ★★★★ | 有边界情况或易错点 |
| ★★★★★ | 综合运用整个 Level 的全部内容 |

## 五、目录分工

- `小喵咪学编程/` —— 教材，有讲解有答案，自学用
- `学习成果考核/` —— 考核，只有题目，无答案，限时做

两者不混。教材里出现的题不许再出现在考核里。
