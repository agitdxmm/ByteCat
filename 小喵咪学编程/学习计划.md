# 学习计划

> 教材已经全部写好，这份是「怎么把它学完」的计划。

---

## 一、整体路线图

```
初一上  Python 基础      L1 ~ L5       ← 现在在这里（教材已 100% 完成）
初一下  Python 进阶      L6 ~ L10
初二    前端三件套        HTML / CSS / JavaScript
初三    C++
高中    C（高级用法）
大学    汇编
```

**为什么是这个顺序：**

- Python 语法干净、能立刻看到结果，适合建立「编程是什么」的感觉
- 前端三件套是「看得见」的东西，初二做网页最有成就感
- C++ 开始接触「内存」「类型」，需要前面的基础
- C 和汇编是「贴着硬件」的语言，放到最后

不用急着往后跳。**每学完一级，前面的东西会变成工具，而不是负担。**

## 三、一周怎么安排

### 推荐节奏

一课 4 个文件，**别一次全做完**。

| 时间 | 做什么 |
|---|---|
| 周一 | 第 1 个文件：读讲解 + 跑示例 + 做 3 道题 |
| 周二 | 对答案，改错 |
| 周三 | 第 2 个文件 |
| 周四 | 对答案，改错 |
| 周五 | 第 3、4 个文件（这两个通常最简单或最综合） |
| 周六 | 对答案 + 把这一课 4 个文件连起来看一遍 |
| 周日 | 休息，或者补没做完的 |

**核心：做完一个文件就停下来对答案，别攒。**

攒着做，错了会一路错下去，回头改更累。

### 一个文件怎么学

```
① 先读讲解区 —— 读一遍，不懂的地方先跳过
② 跑示例 —— 不看讲解，先猜输出，再运行对照
③ 做 3 道题 —— 卡住就翻回讲解区，别翻答案
④ 对答案 —— 一个文件全部做完再对
⑤ 改错 —— 把错的记下来（为什么错，不是正确答案是什么）
⑥ 合上教材 —— 试着不看任何东西，把示例重写一遍
```

第 ⑥ 步最重要。**能默写出来才算会了。**

## 四、检查点：怎么知道自己学会了

### 每课结束

能不看教材，把这一课 4 个文件的示例代码各写一遍，跑通。

写不出来的地方，就是没懂的地方。

### 每个 Level 结束

做考核题，**4★ 和 5★ 能独立完成**（可以查教材，但不能看答案）。

- 5 题做出 4 题以上 → 这一级过关
- 5 题做出 3 题 → 把错的那题对应的课重看一遍
- 5 题做出 2 题以下 → 这一级重学

### 三个「真的会了」的信号

1. **能给别人讲明白**——哪怕是对着空气讲
2. **看到报错不慌**——知道该看哪一行、那句话什么意思
3. **能改别人的代码**——看到一个能跑的程序，知道该动哪里

## 五、卡住了怎么办

### 三种卡法，三种解法

**卡法一：看不懂这段代码在干什么**

→ 一行一行加 `print`，把中间值打出来。看它到底变成什么了。

（L3 第 5 课 03 讲了这一招，叫「print 调试法」）

**卡法二：报错了不知道什么意思**

→ 从左往右读报错，读到冒号后面那句话。那句话是给人看的。

```
TypeError: can only concatenate str (not "int") to str
           ↑ 这一句才是重点
```

**卡法三：题做不出来**

→ 先写出「如果我是人，我会怎么一步一步做」，再翻译成代码。

比如「找最大值」：人是怎么做的？先记住第一个，然后一个个比，比它大就换。翻译过去就是循环 + if。

### 什么时候该问

自己想了 **20 分钟**还不动，就问。

20 分钟够你想清楚「我到底卡在哪一句」—— 带着这句话去问，比自己闷两小时有用。

### 什么时候不该问

一卡住就问。

编程里 80% 的时间都在「卡住」，那是正常的。**卡住本身不是问题，放弃才是。**

## 六、每天花多久

| 阶段 | 每天 | 说明 |
|---|---|---|
| L1 期间 | 30~40 分钟 | 语法简单，但手感要练 |
| L2~L3 期间 | 40~60 分钟 | 开始要想逻辑了 |
| L4~L5 期间 | 60~90 分钟 | 代码变长了，调试要时间 |

**别一次学 3 小时。**

编程是「手感」的活，每天摸 40 分钟，比周末突击 4 小时管用得多。

## 八、如果学期时间不够

现在已经是 11 月，如果这学期只剩不到 15 周，用压缩方案：

| 周次 | 内容 |
|---|---|
| 第 1~2 周 | L1 全部 5 课（一天 2~3 个文件） |
| 第 3~4 周 | L2 全部 |
| 第 5~7 周 | L3 全部 |
| 第 8~10 周 | L4 全部 |
| 第 11~13 周 | L5 全部 |

**但压缩有代价：**

- 每天要多花一倍时间
- 练习要跳一部分（只做第 1、3 题，跳过第 2 题）
- 考核必须做，那个不能省

**我的建议：宁可不学完 L5，也别为了赶进度把 L1~L3 学虚了。**

L1~L3 是地基。地基虚了，L4、L5 会越学越痛苦，最后卡在「每个字都认识但连不起来」。

## 九、学完之后

L5 结束时，你应该能：

- 看懂一个 200 行以内的 Python 程序
- 独立写出「读数据 → 处理 → 输出报告」这一类工具
- 报错时知道去哪找问题
- 知道「这件事标准库大概有现成的」

**这时候可以开始写自己的东西了。**

不用等「学完所有语法」—— 永远学不完。

写点自己想要的工具：成绩统计、记账、单词卡、小游戏、批量改文件名……

写着写着发现「这里需要个新知识」，再回来查、来学。

**这才是编程真正的学习方式。**
